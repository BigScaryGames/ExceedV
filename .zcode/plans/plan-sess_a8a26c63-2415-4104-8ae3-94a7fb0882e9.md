# Autosave for the vault editor (Obsidian-style)

## Goal
Edits save themselves — no manual Save button. Saves stay debounced, delta-based, and surgical (server side already applies splices against the file's current parse, so concurrent Obsidian edits elsewhere in a file are not clobbered).

## Design

### 1. `useAutosave` hook (new, exported from `fields.tsx`)
- Arms a 1.5 s timer whenever the record is dirty and no save is in flight; resets on every keystroke (effect deps: record, orig, dirty, saving, blocked).
- After a save completes, `orig` changes → the effect re-runs → if still dirty (user typed mid-save), it re-arms. No stranded dirty state, no overlapping saves.
- `blocked` = last save failed. A failed save shows an error and does NOT retry in a loop; it retries on the next edit (which clears the flag).

### 2. Race-safe save completion (RecordView + InlineGrantEditor)
- `save()` captures the record snapshot at call time; on success it does `setOrig(saved)` and `setRecord(cur => cur === snapshot ? saved : cur)` — edits typed while the request was in flight are never clobbered by the server response (currently `setRecord(saved)` is unconditional; with autosave that becomes a real hazard).
- Transient "saved ✓" note that fades after ~2 s (InlineGrantEditor already has `savedNote`; add clearing + reuse the pattern in RecordView).

### 3. Flush on leave (both editors)
- `RecordView`: cleanup effect keyed on `path` (refs hold latest record/orig) — flushes pending edits when navigating record→record AND on unmount (record→browse). This also fixes a latent bug: today record→record navigation silently discards unsaved edits.
- `InlineGrantEditor`: same flush on unmount (closing the inline editor or navigating away).
- Flush = same `api.save(buildSavePayload(...))` + `onSaved()` refresh; fire-and-forget with `.catch(() => {})`.

### 4. UI changes
- Remove the **Save** button from the RecordView header and from InlineGrantEditor ("I don't want to manually save", Obsidian-style). "Mark draft" stays an immediate explicit toggle.
- Replace the "● unsaved changes (…will be rewritten)" warning banner with autosave status: dirty → "● unsaved — autosaving…", in-flight → "saving…", success → "saved ✓" (fades), failure → "save failed: … — retries on your next edit" in red. Dirty dot stays.
- `AUTOSAVE_DELAY_MS = 1500` constant.

### 5. Unchanged
- `toggleDraft` (explicit action, saves immediately), Create/Rename/Delete dialogs (separate endpoints), server code (zero changes), `buildSavePayload` delta logic.

## Non-goals
- No beforeunload warning (1.5 s window makes loss practically impossible; unload flushes are unreliable).
- No Obsidian live-reload/conflict detection — same-region concurrent edits raced within the debounce window behave exactly as with manual save today.

## Verification
- `npm run build` (TS) + Python suite stays green (608 — no server changes).
- Browser checks: type in a field → file on disk changes ~1.5 s later with no button click; navigate mid-edit → change flushed; inline grant editor autosaves on close; keep the vault byte-identical on a no-op pass.
