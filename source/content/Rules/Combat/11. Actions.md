NOTE: This represents combat actions not life skilled one - those will have a separate home.

## Core Principle

Primary trait defines mechanical template. Secondary traits modify behavior.

**Action Format:**
```
Action Name | AP Cost
Primary Trait, Secondary Traits
Description
```
