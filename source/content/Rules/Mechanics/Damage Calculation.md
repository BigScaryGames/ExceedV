## Damage Formula
`Damage = Weapon Damage + Strength + Bonuses`
Criticals double the WeaponDamage — see [[Critical Results and Critical Hits]].
## Damage Dice by Prowess Tier

Attacks roll the Prowess domain, so the dice scale with your Prowess tier:

| Prowess Tier | Weapon Dice |
| ------------ | ----------- |
| 0-1          | 1           |
| 2-3          | 2           |
| 4-5          | 3           |

## Weapon Dice by Weight

| Heavy  | d8/d10       | 4              |

## Offensive Attributes

All melee weapons can use **Agility** as the main stat for offensive maneuvers.

- **Heavy:** Allows using Strength (generally heavy, blunt weapons)
- **Finesse:** Allows using Dexterity (generally piercing/slashing weapons)
- **Ranged:** Uses Dexterity or Perception (Guns #TBD) based on weapon type

Certain perks allow you to change the used attribute.

## Damage Application

Damage depletes Stamina first, then Health. See [[HP And Wounds]] for details.
