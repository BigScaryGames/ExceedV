To roll for a consequence, first ask 3 questions and modify the consequence roll.
1. Was it a non-lethal strike?
2. Was it a crit?
3. Was it a DoT?

Consequence Roll = 1d100 - (Remaining Wounds × 10).

1. Non-lethal - roll 1d20 on the consequence table instead of the normal consequence roll.
2. If it was a Critical Hit - add +10 to the roll.
3. If it was a DoT - count the consequence as a cosmetic injury.
