To roll for a consequence, first ask 3 questions and modify the consequence roll.
1. Was it a non-lethal strike?
2. Was it a crit?

Consequence Roll = 1d100 - (Remaining Wounds × 10). The Wounds penalty applies to **lethal** wounds only.

A result below 0 counts as 0 — always a nonlethal, cosmetic Severity 0 consequence.

1. Non-lethal - roll 1d20 on the consequence table instead of the normal consequence roll; the Wounds penalty does not apply.
2. If it was a Critical Hit - add +10 to the roll.
