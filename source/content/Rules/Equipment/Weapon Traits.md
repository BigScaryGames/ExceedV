
| Tier 0 Trait           | Effect                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **Second weapon type** | Select a second weapon type to use perks with, add an alternative physical damage type. |
| **Nonlethal**          | Can select to do nonlethal damage.                                                      |
| **Concealed**          | Can be attempted to be concealed on body or as something else.                          |
| **Reach**              | Can attack targets in zone without engaging.                                            |

| Tier 1 Trait           | Effect                                                                                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Finesse**            | Can use DX instead of AG for attacks and deflects - Light and Medium only.                                                                                  |
| **Secondary attack**   | You can make a 2AP stike with the weapon - a pommel one, or hitting with the spear but. It counts as light weapon for the strike (both damage and AP cost). |
| **Quick drawn**        | Can be drawn out as a part of the attacking action.                                                                                                         |
| **Sweep**              | Each consecutive hit in multi-target abilities deals +1 damage.                                                                                             |
| **Range**              | Bows start here. The range is 10 × weapon Tier meters.                                                                                                      |
| **Returning (Thrown)** | When thrown, returns to the hand as a single action to pull it back.                                                                                        |
| **Versatile**          | Can be used in two hands increasing die size.                                                                                                               |

| Tier 2 Trait          | Effect                                                                                                                                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Conduit**           | Hands holding count as free for spellcasting purposes.                                                                                                                                                                         |
| **Parry**             | +1 to Deflect if not using shield.                                                                                                                                                                                             |
| **Intimidating**      | +2 to Intimidation checks with the weapon brandished.                                                                                                                                                                          |
| **Inspiring**         | +2 to Leadership actions with the weapon brandished (if reasonable).                                                                                                                                                           |
| **Supernatural Bane** | Dragonbane, Undeadbane, etc. Extra damage equal to weapon die.                                                                                                                                                                 |
| **Poison Container**  | With an action apply poison to the weapon. Can do Tier times.                                                                                                                                                                  |
| **Serrated**          | +20 to wounds roll.                                                                                                                                                                                                            |
| **Bonded**            | A magic link between you and the weapon. Other's cannot weild it without an unbonding ritual or killing the owner, the weapon can be summoned while within 100 meters radius. Owner knows the general direction the weapon is. |

|  Tier 3 Trait        | Effect                                                                                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Elemental Damage** | Replace damage with an elemental one for an attack. 1 action to switch on/off. Tier 4 and 5 weapons with this trait can have 2/3 types of elemental damage.          |
| **Vampiric**         | On a hit, a living creature with blood rolls Endure against the weapon (Tier × 2 + 10). On failure they lose extra HP equal to half AP spent, you heal that much HP. |
| **Animated**         | The weapon fights on its own. It has an attack bonus of its Tier and attacks once per turn on your turn. Limit cost = hands to wield.                                |
| **Dimensional**      | Melee variant - your attack range increases to adjacent zones. Ranged variant - all range penalties are reduced to second range.                                     |
