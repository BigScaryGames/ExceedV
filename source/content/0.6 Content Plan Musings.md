## 0.6 Vocabulary Rename (changelist)

Executed across the vault. Parsers/apps reading `source/content/` must update to this vocabulary.

**Core principle: a perk's tags say what it IS; its Cost line says which XP pays for it. Tags never carry the currency.**

| Concept | Old | New | Notes |
|---|---|---|---|
| Magic domain | Spellcraft | **Magery** | Roll stat, tier gates, `[Magery]d4` damage notation |
| Combat domain | Martial | **Prowess** | Roll stat (`Prowess + ST/AG vs Endure`), requirement lines (`Prowess 1`) |
| Physical attribute | Might (code `MG`) | **Strength** (code `ST`) | Attribute codes now `PR WL CH WT ST EN AG DX` |
| Combat currency | Combat XP / Combat Flaw | **Battle XP / Battle Flaw** | Earned from battles; funds Prowess perks, Magery perks + spells, Conditioning, combat skills |
| Non-combat currency | Skill XP / Skill Flaw | **Life XP / Life Flaw** | Earned during life sessions; funds life skills and `#Skill` perks |
| Fighting perk tag | `#Combat` | **`#Prowess`** | Fighting techniques/weapon trees; XP advances the Prowess domain |
| Magic perk tag | `#Spellcraft` / `#Magic` (perk side) | **`#Magery`** | XP advances the Magery domain |
| Conditioning tag | `#Combat #Conditioning` | **`#Conditioning`** (+ `#Leveled`) | No `#Prowess` — conditioning advances no domain |
| Life-skill perk tag | `#Combat`-era `#Skill`, briefly `#Life` | **`#Skill`** | Life-skill applications |
| Battle-side "other" perks | `#Combat` | **no discipline tag** | Plot Armor, That Type of a Person, The Loner, Too Selfish, Watching your back, Reactive, the Predictive line, Leadership — identified by a Battle XP cost alone |
| Cost line format | `**Cost:** 5 XP` | **`**Cost:** 5 Battle XP`** / `**Cost:** 5 Life XP` | Variable: `**Cost:** Variable (Max_Wounds × level), Battle XP` |
| Perk folder | `Perks/CombatPerks/` | **`Perks/BattlePerks/`** | Path rename |
| Perk folder | `Perks/SkillPerks/` | **`Perks/LifePerks/`** | Path rename; will also hold non-skill life advantages (looks, standing, languages) |
| Mechanics file | `Rules/Mechanics/Spellcraft Progression.md` | **`Rules/Mechanics/Magery Progression.md`** | Embed target of `![[Magery Progression]]` |

Unchanged on purpose: `#Magic` as a *mechanic-file* usage tag (magic-system rules), `#Metamagic`, `MagicPerks/` folder, `#Combat` as the *usage* tag on action/mechanic files ("relevant during fights"), and the word "combat" for the activity (chapter titles, "in/out of combat" prose).
