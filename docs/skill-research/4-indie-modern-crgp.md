# Indie, modern & CRPG systems on skills

*Research report for the ExceedV skill rework. Fourth wave: systems outside the d20/GURPS/career lineages. Blades in the Dark verified against the official SRD (bladesinthedark.com); others from rule knowledge, flagged where thin.*

## Blades in the Dark — a dozen actions, no skill list

No skill list at all. Characters have **action ratings** grouped under three attributes — **Insight** (Attune, Hunt, Study, Survey), **Prowess** (Finesse, Prowl, Skirmish, Wreck), **Resolve** (Command, Consort, Sway) — rated 0–4. You don't pick a skill for a task — **you pick the action from what your character is doing in the fiction** ("If you want to roll your Skirmish action, then get in a fight"), the GM sets Position & Effect, and the roll is a dice pool where only the highest die counts. Advancement: **XP for rolling an action in play** (especially failures) — use IS progression. Specialization lives in **playbook items and upgrades**, not the ratings. Verified from the SRD's six-step Action Roll procedure (state goal → choose action rating → position → effect → bonus dice → roll). The radical move: **breadth is free and narrative; the list is verbs from day one.** Depth beyond 4 doesn't exist; competence beyond dice is fiction + gear + crew.

## Burning Wheel — skills as recorded biography

Lifepath chargen: characters built by walking lifepaths (Born → village → profession…), each granting named skills at opening counts — skills read like a résumé. Advancement by **tests**: only *challenging* tests mark a skill for advancement (grind-proof by construction). **Fork dice**: related skills add a die to the pool — formal adjacency bonus. **Wises**: player-authored narrow knowledge skills ("Rat-wise", "City Guard-wise") — the strongest player-authorship pattern in the trad-adjacent space. **Circles**: a social skill for finding contacts — relationships as a rollable rating. (Rule knowledge; general structure verified via Wikipedia.)

## Torchbearer 2e — Beginner's Luck as the elegant untrained rule

Skills tested as d6 pools vs obstacle; **Beginner's Luck**: attempt an untrained skill by rolling its root attribute with a doubled requirement — expensive but possible, and enough successful tests eventually "open" the skill properly. The cleanest untrained-use rule in the business: untrained = attribute roll + tax + a path to earning the skill by doing. (Rule knowledge.)

## Fate Condensed — pyramid, stunts, aspects: three clean layers

~18 broad skills rated +0..+4 with a **pyramid/column distribution at chargen — the pyramid IS the breadth price**: you cannot be narrow without also being broad. **Stunts** = the verb layer (~1 refresh each): "Because I am a Master Duelist, I gain +2 to Fight when…". **Aspects** cover identity entirely — no profession mechanics at all. The cleanest separation in the industry: skills (numbers) / stunts (verbs) / aspects (identity).

## Cortex Prime — skills as an explicit design dial

A build-your-own-system toolkit: "skills" are just one possible **trait set** (alongside attributes, distinctions, roles…) the table assembles; SFX are the verb layer. Lesson: treat "how do skills relate" as an explicit design dial, not a fixed ontology.

## The One Ring 2e — skills carrying undertakings

~18 skills, each with associated **Undertakings** — travel and council endeavors are resolved by choosing which skill you roll (Explore, Track, Hunt…). Skill levels gate which endeavors you can lead. Modern low-crunch convergence: **broad skills, each carrying its own verb list.** (Rule knowledge.)

## Savage Worlds — die steps and cheap breadth

Skills bought with points as **die types** (d4–d12) paired to a core attribute; Wild Cards roll trait die + d6 Wild Die, success at 4+. d4 costs 1 point — breadth is nearly free; depth is die steps. **Edges** (the feat layer) gate on skill die types ("requires Fighting d8") — the same rank-gates-verbs pattern as PF2e, in a non-d20 chassis. (Rule knowledge.)

## CRPG lineage — Fallout & Elder Scrolls

- **Fallout 1/2 (SPECIAL):** skills as percentages, **three Tag Skills** (+20% and 2× growth rate — a cheap depth tag), 3–4 picks from a ~18-skill list; Intelligence gates skill points per level. **Fallout 3/NV:** skill books and bobbleheads as diegetic +skill findables; NV's Hardcore mode ties Survival skill to cooking/poison resist — utility skills as **economy gates**. **Fallout 4:** skills abolished entirely — the **perk chart IS the skill list** (each SPECIAL rank row = perk ranks); Bethesda concluded players couldn't tell perks from skills and merged them — a warning about maintaining two parallel competence layers without clear jobs.
- **Elder Scrolls:** skills grow **by use** (jump to level Jump), with **trainer-purchased levels capped per level-up** — a hybrid: organic growth + point buy, each covering the other's failure mode. Skyrim then collapsed skills (~21→18) and moved identity from class (removed) to **standing stones/guilds** — identity again fleeing the skill list.

## 5 structural ideas worth stealing

1. **Blades: the list as verbs** — if a rating exists, it's because you DO it; nothing on the list that isn't an action in fiction.
2. **Torchbearer Beginner's Luck** — untrained use = attribute + tax + earn-in by doing; dovetails with a defaults layer.
3. **Fate pyramid** — breadth priced by *distribution shape*, not per-item cost; narrow characters forced to be somewhat broad.
4. **BW Wises / advancement-by-challenge** — player-authored narrow skills; advancement gated by difficulty, not repetition.
5. **CRPG warning + TOR undertakings** — keep skill and perk layers' jobs distinct (Fallout 4's merge) or they collapse; attach verb lists directly to skills (TOR).

## 3 traps to avoid

1. **Two parallel competence layers without distinct jobs** — Fallout 4 had to merge skills into perks; ExceedV's Martial/Spellcraft domains already hold combat/magic competence, so the skill list must be *utility-only* with zero combat overlap.
2. **Progression-by-use bookkeeping at the table** — fine for a CRPG tracking jumps, tax for a TTRPG (echoes report 3's trap).
3. **Identity mechanics welded to the list** — every system that tried (class-skill taxes, tagged professions) shed them; identity belongs in packages/aspects/standing stones.
