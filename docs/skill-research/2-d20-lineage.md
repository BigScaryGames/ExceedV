# The d20 lineage on skills

*Research report for the ExceedV skill rework. Sources: verified live against d20srd.org (3.5 SRD) and 2e.aonprd.com (PF2e remaster). 4e/5e details from standard references; 4e skill-power examples are memory-attested (PHB3), flagged below.*

## D&D 3.5 / Pathfinder 1e — deep ranks, taxed breadth

Skills bought with **skill points** (per level, by class + Int). One point = **1 rank** class skill, **½ rank** cross-class; max rank = level+3 (class) or half that (cross-class). ~35 fine-grained skills (Hide vs. Move Silently vs. Spot vs. Listen vs. Search). **Synergy bonuses**: 5 ranks → **+2** to related skills — an explicit depth reward. Specialization as subskills: **Craft (Type)**, **Knowledge (Field)**, **Profession (Whatever)**. PF1 later merged perception skills and replaced cross-class cost with a flat **+3 class-skill bonus** when trained.

## D&D 4e — binary training, skills as power source

Skill modifier = ½ level + attribute, **+5 if trained**. No ranks: breadth is a handful of trained picks at level 1; depth is automatic (half-level) but flat. The big idea: **Skill Powers** (PHB3) — level 2/6/10 **utility powers keyed to a skill**, swapped in place of class utility powers, requiring training in that skill. Examples (memory-attested): **Great Leap** (Acrobatics 2 — jump your speed), **Agile Recovery** (Acrobatics 2 — stand from prone as minor action), **Arcane Mutterings** (Arcana 2 — substitute Arcana for Bluff/Diplomacy/Intimidate). Skills as loadout verbs.

## D&D 5e — bounded, gated, mostly passive

One **proficiency bonus** (+2→+6) shared across skills, saves, tools, attacks. Proficiency *gates* rather than scales: untrained ≠ incapable, but tools/armor/weapons/features require it. **Expertise** (rogue/bard) doubles proficiency on chosen skills — the only depth mechanic. **Reliable Talent** (rogue 11): proficient checks treat d20 rolls under 10 as 10. **Backgrounds** grant 2 skills + tools + a feature — profession fantasy as a *starting package*, not progression.

## Pathfinder 2e — ranks as gates, four degrees of success

Check = d20 + attribute + level + proficiency bonus (**U/T/E/M/L = +0/+2/+4/+6/+8**). Four degrees: crit success (≥DC+10) / success / failure / crit failure (≤DC−10) — investment buys better *outcome tiers*, not just odds. **Sample task DCs by rank** (verified on AoN Athletics): Climb — untrained: ladder; trained: rigging; expert: wall with handholds; master: rock wall; legendary: smooth surface. **Skill feats** gate verbs behind ranks: **Assurance** (trained), **Group Coercion** (trained Intimidation; 5→10/25/50 targets at expert/master/legendary — verified), **Robust Recovery** (expert Medicine), **Battle Cry** (master Intimidation), **Battle Medicine** (trained Medicine; in-combat healing, 1/day per target), **Cat Fall** (trained Acrobatics; falls treated as 20 ft shorter, scaling with rank), **Legendary Sneak** (legendary Stealth — sneak without cover, full speed). **Lore** sub-skills (Warfare Lore, Cooking Lore) are the specialization layer. Backgrounds grant one trained skill + a skill feat; archetypes buy skill-flavored feat chains.

## The four questions

- **(a) Breadth vs. depth pricing:** 3.5 prices both in points, depth cheaper in-class; 4e prices breadth only, depth free but flat; 5e prices breadth cheaply, depth only via Expertise; PF2e prices depth in a public rank ladder + breadth in picks and skill feats.
- **(b) Gating verbs:** 3.5 — training-only skills + synergy; 4e — skill powers need training; 5e — proficiency gates tools/features, rarely verbs; PF2e — feats and actions gated by named rank, scaling with it.
- **(c) Specialization:** subskills (Craft/Knowledge/Profession/Lore); absent by design in 4e/5e.
- **(d) Professions:** 5e backgrounds = one-time package; PF2e background = trained skill + skill feat; PF2e archetypes = ongoing skill-themed chains.

## 5 structural ideas worth stealing

1. **PF2e rank-gated verbs**: hang perks on named skill levels so every perk is an unlocked action.
2. **PF2e degrees of success**: 2d10 spread maps to crit bands — levels improve *outcome tiers*, not just totals.
3. **PF2e sample tasks per rank**: publish "what each level lets you attempt" per skill — kills stat-stick skills by construction.
4. **4e skill powers**: level-gated utility options chosen per skill — verbs as loadout.
5. **5e backgrounds / PF2e Lore**: profession fantasy as a *starting package + narrow subskill* — decouple "who I was" from "what I buy."

## 3 traps to avoid

1. **3.5 fine-grained overlap** (Hide/Move Silently, Spot/Listen/Search): list bloat taxing breadth — every successor consolidated.
2. **Synergy micro-bonuses**: +2 bookkeeping webs rewarding system mastery over play.
3. **Auto-scaling untrained competence** (4e half-level, 5e anyone-can-try): if untrained keeps pace, depth investment stops feeling heroic — gate the verbs, allow improvised attempts at a price.
